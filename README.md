## Curriculum Additions

This repository tracks curriculum additions for the 4-12 program. Some additions may appear in more than one class on purpose when they are intended to be taught as part of multiple core learning paths.

## Addition 1: Distributed Systems Core

### Capstone Project Blueprint: The Hive-Mind Student Mesh
**Program Track:** Distributed Systems, Collective Intelligence, & Sustainable Architecture

#### Project Overview
The Hive-Mind Student Mesh moves students away from isolated, siloed learning and into a collaborative, decentralized collective. Modeled after distributed edge-computing networks and low-bloat data architectures, this project trains student cohorts to function as a synchronized node network—sharing clean data, filtering out digital noise, and solving complex regional challenges together.

#### Core Objectives
- **Collective Intelligence:** Demonstrate how a coordinated group sharing high-utility data outperforms isolated traditional models.
- **Distributed Problem Solving:** Divide a large-scale civic or environmental challenge (such as regional transit efficiency, rail spur revitalization, or micro-weather monitoring) across student sub-nodes.
- **Anti-Bloat Protocols:** Enforce strict data hygiene—ensuring every piece of shared information is purposeful, verified, and stripped of digital spam before entering the collective mesh.

#### Operational Mechanics & Phases
1. **Node Initialization & Query Training**  
   Each student or small team establishes their local node, applying foundational query strategies and noise-reduction techniques to gather primary data on a specific assigned sector.
2. **Local Edge Processing & Filtering**  
   Students process raw findings locally, distilling bulk data into high-value insights, metadata, and actionable intelligence rather than unorganized storage dumps.
3. **Mesh Synchronization & Collective Synthesis**  
   Student nodes connect through a shared repository or local exchange protocol and aggregate their cleaned insights into a unified Super Mesh model.

#### Comparative Evaluation
- Compare the output, speed, and accuracy of the student Hive-Mind Mesh against a simulated traditional model burdened by administrative spam and redundant individual busywork.
- **Key Metric:** Total useful signal generated versus energy, time, and computational waste expended.

#### Final Deliverable
- **The Regional Blueprint:** A fully synchronized, open-source collective intelligence report and interactive map maintained entirely by the student mesh network.

## Addition 2: Sustainable Architecture Core

### Capstone Project Blueprint: The Hive-Mind Student Mesh
This capstone is intentionally included in this second core class as well so students encounter the same collaborative systems project through the lens of sustainable architecture and regional infrastructure planning.

#### Focus in this class
- Regional infrastructure mapping
- Transit and rail spur revitalization analysis
- Energy and feasibility considerations
- Ecological opportunity identification
- Sustainable systems design through shared intelligence

#### Shared Deliverable
- The same synchronized Regional Blueprint is used here as a class-owned capstone outcome, ensuring both core classes include the project as part of their required learning sequence.
